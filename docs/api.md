### fn `normalize_inbound`

Verify and normalize a raw CircleCI webhook request.
CircleCI signs the raw body with HMAC-SHA256 and ships the digest in a
comma-separated, versioned `circleci-signature` header (`v1=<hex>`). We
recompute the highest known version and compare in constant time. When no
signing secret is configured we fail closed. There is no timestamp in the
signature, so dedup happens on the top-level delivery `id` instead.
